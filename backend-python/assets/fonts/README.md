# Font Files for SVG Text-to-Path Export

Place Kanit TTF files here to enable the "Convert to Paths" SVG export mode.

Download from: https://fonts.google.com/specimen/Kanit

Required files:
- Kanit-Regular.ttf   (weight 400)
- Kanit-Bold.ttf      (weight 700)
- Kanit-Black.ttf     (weight 900)

The embed-fonts export mode works without these files (uses bundled woff2 from @fontsource/kanit).
